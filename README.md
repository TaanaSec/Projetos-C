# Projetos em C

Repositório criado para armazenar meus projetos e exercícios desenvolvidos durante meus estudos da linguagem C.

## Projetos

### 1. CaixaFácil — Sistema de Caixa para Lanchonete

**Status:** Concluído com possíveis bugs — versão inicial

O CaixaFácil foi o primeiro projeto que desenvolvi em C pra colocar em prática o que eu estava aprendendo nas aulas. O projeto foi desenvolver um sistema bem simples de caixa pra uma lanchonete, com menu interativo, cadastro de pedidos, cálculo de valores e relatório de vendas.

O projeto foi desenvolvido utilizando apenas os conhecimentos básicos de C que eu estou aprendendo, principalmente estruturas condicionais e estruturas de repetição.

#### Funcionalidades

- Menu principal com opções para novo pedido, relatório de vendas e encerramento do sistema.
- Cardápio com quatro produtos: hambúrguer, batata frita, refrigerante e cachorro-quente.
- Registro de pedidos com diferentes produtos e quantidades.
- Cálculo automático do subtotal de cada pedido.
- Aplicação de 10% de desconto em pedidos com valor igual ou superior a R$ 50,00.
- Exibição do resumo do pedido, incluindo subtotal, desconto e valor total.
- Relatório com quantidade de pedidos finalizados, faturamento, descontos concedidos e valor médio dos pedidos.
- Validação de opções do menu, produtos e quantidades.

#### Conceitos praticados

Durante o desenvolvimento foi praticado:

- Variáveis e tipos de dados (`int` e `float`).
- Entrada e saída de dados com `scanf()` e `printf()`.
- Estruturas condicionais (`if`, `else if` e `else`).
- Estrutura de repetição `do while`.
- Acumuladores e contadores.
- Cálculos matemáticos e porcentagens.
- Validação básica de entradas.
- Organização da lógica de um programa.

#### O que aprendi

Aprendi a combinar diferentes conceitos da linguagem e resolver um problema na pratica. Em vez de trabalhar apenas com exercícios isolados, precisei organizar as etapas dele, controlar a repetição dos menus, calcular os valores e manter os dados das vendas durante a execução.

Também identifiquei erros de lógica e melhorarei o programa aos poucos enquanto testava.
